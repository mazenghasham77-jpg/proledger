# Bootstrap Admin Guide

Use this process after first deployment.

## 1. Create admin user
Create one administrator with:
- full name
- email
- strong password
- admin role

## 2. Company setup
Enter:
- company name
- legal name
- base currency
- tax number
- fiscal year start

## 3. Finance setup
Confirm:
- chart of accounts
- inventory asset account
- revenue accounts
- expense accounts
- COGS account
- VAT/tax accounts

## 4. Operations setup
Create:
- warehouses
- bank accounts
- customers
- suppliers
- products
- inventory items

## 5. Controls
Create:
- first accounting period
- number sequences
- approver users if needed

## 6. Smoke test
Run:
- one invoice
- one payment
- one bill
- one inventory receipt
- one inventory issue
- one bank import
