# Architecture Summary

## Frontend
- Next.js app
- login and dashboard views
- API-driven business modules
- deployment-ready container setup

## Backend
- Express API
- Prisma ORM
- PostgreSQL database
- role/auth middleware
- business controllers
- reporting endpoints
- health endpoint

## Data domains
- company / users / roles
- accounting / journals / reports
- sales / invoices / receivables
- purchases / bills / payables
- inventory / balances / movements
- approvals / periods / audit
- bank / reconciliation
- attachments / documents
